## 🧠 Project Overview

Buy Now, Pay Later (BNPL) services like Affirm, Klarna, and Afterpay 
have transformed consumer credit — enabling zero-interest installment 
purchases at checkout with minimal underwriting. But with $70 billion 
in transactions in 2025, 41% of users making late payments, and 45% 
of loans going to deep subprime borrowers, the financial risk is real 
and largely invisible.

The project follows an end-to-end data science workflow that:
- **Models** borrower default risk using supervised learning methods
- **Integrates** borrower-level, macroeconomic, and behavioral data into a single analytical dataset
- **Applies** SHAP to support interpretation of model predictions
- **Incorporates** scenario-based analysis to evaluate how risk changes under different economic conditions
- **Deploys** the final model in an interactive Streamlit dashboard
  
👉 Live App: https://bnpl-risk-intelligence.streamlit.app/

---

## ❓ The Central Question

> Can a data-driven, interactive system be developed to estimate borrower
> default risk in BNPL-like settings and allow users to explore how that
> risk evolves under different economic scenarios?
